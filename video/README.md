# `videos/` Folder Description

This folder contains links to demonstration videos of the R2M robot performing the **Open Challenge** and **Obstacle Challenge**.  

Each video showcases the autonomous capabilities of the robot, including navigation, obstacle detection, and cornering. The videos are intended to provide visual proof of the vehicle’s performance for competition documentation and judging.
